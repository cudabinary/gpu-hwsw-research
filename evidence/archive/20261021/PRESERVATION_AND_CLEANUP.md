# Preservation and cleanup

원격 보존·전체 내용 검증·실제 복원만으로 모든 로컬 원본을 자동 삭제하지 않는다. 사용자는 백업 완료 후 PC 정리를 승인했지만, 활성 MAIN/RCC·다른 진행 중인 연구와 유일본은 보호한다.

DELETE_CANDIDATE에는 원격 검증과 실제 복원, 추가 독립 백업, 비활성 사용 상태가 모두 확인된 자료만 포함한다. 동일 PC의 다른 폴더는 다른 물리 장애 영역의 백업이 아니다. GitHub에서 실제 내용 복원까지 확인된 파일은 B2와 별도 원격 보존 여부를 따로 판단한다. 원본 삭제 사실·해시·원격 복원 위치는 별도 감사 원장으로 기록해야 한다.

이 인덱스의 발행 자체는 삭제 증명이나 추가 백업 확보를 의미하지 않는다. 로컬 위치의 정리·검증 결과는 별도 실행 보고서와 원장을 확인한다.
