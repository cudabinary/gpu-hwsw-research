## Limited candidate1: same-operator repeated-RHS Poisson solve

Application meaning: solve a discretized elliptic/pressure system; changed RHS with a reused operator is legitimate solver usage. The public KSP interface and convergence reason must be distinguished: a fixed iteration result can be a valid inexact inner solve, but returning without error does not establish convergence. Source: https://petsc.org/release/manualpages/KSP/KSPSolve/ (read2026-10-23). No actual caller/outer solver or request lifetime is in local evidence.

Local evidence: preserved workloads.py PoissonCG is uniform64x64 five-point Dirichlet Laplacian,4096unknowns,20224nonzeros,8 deterministic RHS,32fixed iterations. Its Graph step uses stable A and x/r/p/scalar buffers. A new RHS can be copied during reset outside capture. This describes a legal computational reuse opportunity, **not** a measured cross-request Graph reuse, actual application lifetime or large gain prediction. Choosing more RHS merely to amortize capture is forbidden.

Cheapest mathematical alternative must be checked first: this particular operator is separable. poisson_cpu_check.py uses a DST-I via odd-extension NumPyFFT and the analytic eigenvalues. The DST-I definition/involution reference is https://docs.scipy.org/doc/scipy/reference/generated/scipy.fft.dst.html (read2026-10-23); SciPy itself is not installed or used. An independent8x8 dense sine transform matches the FFT implementation within1.56e-15. At64x64, RHS0/1 direct-solve relative residuals are7.50e-15/2.37e-15, versus32-stepFP64 CG relative residuals0.1201/0.0341. No solver timing is measured, no logical calls converted into GPU time or DRAM bytes.

**Output contract distinction:** direct DST solves the same linear system accurately but does not return the identical fixed32-CG array (max differences4.0685/1.1755). It is a cheap strong alternative only under a solved-system contract, not a drop-in replacement for the old exact32-step output. If a real application deliberately needs an inexact32-step inner operator, that caller and allowed error must be recorded. We do not change the matrix to a harder synthetic one to rescue this candidate.
