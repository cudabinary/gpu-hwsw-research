# Existing-session regime audit

Read `SESSION_COMPARISON.md` first. The single recommendation is to investigate
measurement/state interference before advancing to preparation-inclusive costs.
This is a bounded CPU reaggregation of existing S1/S2/S3 evidence, not another
GPU campaign or correctness/benchmark run. No original source, log, ZIP, strict
guard or RCC worktree was changed.

`calculations` contains absolute changes, per-request/segment components, setup
timers, byte equivalence, preserved telemetry and provenance. `INPUT_MANIFEST.json`
links every captured input to its original workspace-relative path and SHA-256.
`inputs` contains exact copies for independent offline reproduction. Local
absolute paths inside raw records remain private; Git receives sanitized text
derivatives and hash links, with executable/cubin/arrays/XML retained in the
private result delivery. Git and Library delivery do not certify a B2 backup.
